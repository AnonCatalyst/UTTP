# UTTP Area Intelligence

**Prepared:** 2026-11-19
**Classification:** public OSINT / group-level

This folder maps **digital areas** where UTTP activity has been reported or
assessed. It is deliberately **not** an account list.

> **No target list. No usernames. No account IDs. No invite links.**
> Areas are platforms and surfaces, not people. Presence is not a census.

## Headline

UTTP’s footprint is **platform-shaped, not geography-shaped**. The strongest
areas are YouTube, Discord, X, Telegram, Roblox, and the public archive/wiki
layer; weaker or assessed areas include TikTok, Instagram, Reddit, 4chan,
Mastodon, Bluesky, Tumblr, Twitch/Kick, Facebook/Snapchat, and gaming profile
surfaces.

**Do not** convert this register into a list of accounts. A platform surface with
UTTP activity is not a member.
