## Headline

UTTP is a **persistent, fragmented harassment brand**, not a unified organisation.
The 2026 layer is a set of small, community-reported offshoots and campaigns
(Circusfall, OfficerSlappy/UTTP Forum, AFR, Bn0r Empire, RDF/RDFPARTY) plus the
older DPOS bridge. UTTP is **not designated**; 764 and O9A are. The evidence
supports **overlap and edge fusion**, not a merger or operational-arm relationship.

## Use rule

Use the package to prioritise **behaviour, platforms, and harm**, not names. Do
not convert it into a list of people. Report exploitation or imminent harm to the
authorities.
