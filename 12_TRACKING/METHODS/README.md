# Methods tracker

Group-level tracking of **methods**, not people. Each row is a public or
community-documented tactic/adaptation. Confidence labels apply.

`METHOD_TRACKER.csv` columns:

```text
method_id,method,description,platforms,first_seen,last_source_check,confidence,source,notes
```

Use `00_READ_FIRST/CLAIM_LEDGER.md` for confidence definitions. New observations
go through `12_TRACKING/INBOX/`.
