## Headline finding

harassment network** with a police-state aesthetic. It matters because it bridges
UTTP’s youth-targeting raid culture to 764/Com-style grooming, blackmail, and
shock content. The evidence supports **lineage, overlap, and personnel
crossover**; it does **not** support “DPOS is 764,” a merger, or a 764 command
chain.
