# DPOS HTML captures — viewing note

The two `*.html.txt` files in this folder are **byte-for-byte historical HTML
captures** from the DPOS 2025 investigation. They were renamed from `.html` to
`.html.txt` during the 2026-11-19 archive pass so GitHub and browsers open them
as text rather than treating them as an HTML page to download or render.

- Original content is unchanged.
- The `.txt` suffix is a viewer/transport label, not a content conversion.
- If you need the exact original filename for citation, use the old path recorded
  in `00_READ_FIRST/PATH_MAP.md` / Git history; the bytes are the same.
- These captures may contain hostile or disturbing text. Content warnings apply.
