## What "09A Cult" means

"09A Cult" is a **local/community label** used by the archive. It is not the
official name of O9A, and it does not establish that a distinct organisation
called "09A Cult" exists, let alone controls O9A.

The correct expansion is:

- **O9A / ONA** — Order of Nine Angles.
- **09A** — an alternate spelling used in some community material.
- **"09A Cult"** — archive shorthand for the material in this folder.

## Relationship to O9A

O9A is a decentralised, leaderless network of autonomous cells ("nexions"). It
has no established central headquarters. The New Zealand statement of case lists
764, No Lives Matter, and Maniac Murder Cult among O9A nexions; it also says
nexions are operationally independent.

See [`14_O9A_764_TRACE/`](../../14_O9A_764_TRACE/) for the sourced profile and
the 764 trace.
